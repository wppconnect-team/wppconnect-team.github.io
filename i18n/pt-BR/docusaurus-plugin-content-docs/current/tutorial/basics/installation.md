# Instalação do SDK para Node.js

No diretório do projeto, instale o pacote publicado no npm. O comando adiciona o SDK às dependências da aplicação.

~~~bash
npm install @wppconnect-team/wppconnect
~~~

Para testar a [compilação nightly](https://github.com/wppconnect-team/wppconnect/releases/tag/nightly), instale o pacote da release correspondente.

~~~bash
npm install https://github.com/wppconnect-team/wppconnect/releases/download/nightly/wppconnect-nightly.tgz
~~~
