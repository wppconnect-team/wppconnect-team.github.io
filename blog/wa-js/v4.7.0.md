Today we are releasing minor version v4.7.0 for WA-JS with Features, Bug Fixes, Build System, Continuous Integration and Chores.

<!--truncate-->

## Highlights

- Fix Pix key messages and preserve native payment payloads in `WPP.chat.sendPixKeyMessage`.
- Fix native-flow buttons, group sender-key messages, and files with interactive buttons.
- Avoid preloading the native attachment preview UI, resolving the media selection problem reported in #3716.
- Return custom lists in synchronized device order with `WPP.lists.list()`, including `orderIndex`.
- Add `WPP.lists.setOrder(listIds)` to reorder custom lists through WhatsApp's native persistence action. Pass every custom list ID exactly once; built-in list positions and colors are preserved. WhatsApp must enable list reordering for the account.

```javascript
const ids = WPP.lists.list().map(list => list.id);
await WPP.lists.setOrder(ids.reverse());
```

Validated with 179 unit tests, including 15 ordering cases, and all 59 pull request checks. Authenticated phone synchronization and real message sending were not tested in this release run.
