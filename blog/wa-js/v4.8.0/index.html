WA-JS minor release: v4.8.0

November 13, 2026 · 5 min read
WPPConnect Team
Repository

Today we are releasing minor version v4.8.0 for WA-JS with Features, Bug Fixes, Documentation, Build System, Continuous Integration, Chores and BREAKING CHANGE.

4.8.0 (2026-11-13)​

Features​

  • call: add native controls and scoped call audio (7308cf1)

Bug Fixes​

  • chat: resolve newsletters from their own store (#3767) (4595d9e), closes #3767
  • chat: respect native newsletter action lifecycle (#3762) (5f134cb), closes #3762
  • chat: reuse the MsgStore model when reading messages (d8dd1b3)
  • deps: prevent glob amplification and retain import lint rules (#3764) (9065591), closes #3764
  • deps: prevent release tooling response-decoding crash (#3754) (dd533b7), closes #3754
  • loader: recover community participants on current WhatsApp (#3751) (13fec08), closes #3751
  • tolerate removed LID getter while preserving deprecated APIs (2d729a0), closes #2926

Documentation​

  • adopt official WPPConnect branding and API favicon (#3758) (1276b2f), closes #3758
  • publish canonical API URLs and preserve renamed references (#3775) (3b00cce), closes #3775
  • refresh API reference visual design (#3766) (6a617d4), closes #3766
  • standardize bilingual READMEs and support guidance (2479f13)
  • update official WPPConnect logo and API favicon (#3765) (e1bd9e2), closes #3765

Build System​

  • deps-dev: bump fast-uri from 3.1.8 to 3.1.9 (3ee6227)
  • deps-dev: require prettier ^3.10.1 (d2d25ff)
  • deps-dev: update dependency eslint to ^10.14.0 (#3760) (c97f9e4), closes #3760
  • deps-dev: update dependency prettier to ^3.10.0 (69b8db2)
  • deps-dev: update dependency release-it to ^21.1.2 (#3759) (1852440), closes #3759
  • deps-dev: update dependency webpack to ^5.112.2 (#3749) (59d6356), closes #3749
  • deps-dev: update dependency webpack-cli to ^7.3.1 (#3761) (96cecad), closes #3761
  • deps-dev: update playwright monorepo to ^1.65.0 (#3770) (f8c27c2), closes #3770
  • deps-dev: update typescript-eslint monorepo to ^8.72.1 (#3753) (fe73b0a), closes #3753
  • deps-dev: update typescript-eslint monorepo to ^8.72.2 (#3771) (4e0542c), closes #3771
  • deps: update node.js to v24.22.2 (#3756) (a50ccf1), closes #3756
  • deps: update node.js to v26 (#3763) (1b7c75e), closes #3763
  • deps: update node.js to v26.13.1 (cdf4cb0)

Continuous Integration​

  • deps: update dependency node to v26 (#3755) (5c5b6bb), closes #3755

Chores​

  • deps: update prettier to v3.10.1 (67f95b0)

BREAKING CHANGE​

  • WPP.conn.getMigrationState() no longer returns isLidMigrated, and WPP.whatsapp.functions.isLidMigrated and WPP.whatsapp.Lid1X1MigrationUtils.isLidMigrated/setIsLidMigrated were removed. WhatsApp Web >= 2.3000.1054281195 treats every account as LID-migrated.

  • build(deps-dev): update dependency @wppconnect/wa-version to ^1.5.5200

  • fix(loader): load lazy modules exposed only as JSResource

WhatsApp Web 2.3000.1054241206 no longer lists WAWebQueryAndUpdateCommunityParticipantsAction as a Bootloader component: the member modal bundle now loads it on interaction through JSResourceForInteraction. ensureLazyModule skipped it, so WAWebGroupGetCommunityParticipantsJob was never registered and getCommunityParticipants stayed undefined.

Lazy module sources can now list JSResource names, tried after the components when the module is still missing.

  • fix: preserve deprecated LID migration APIs and resource cleanup

For more information, see the release page.
