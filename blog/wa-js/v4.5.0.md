Today we are releasing minor version v4.5.0 for WA-JS.

<!--truncate-->

## 4.5.0 (2026-07-31)

### 🐛 Fixes

- **loader**: wait for WhatsApp's Meta module graph to settle before firing `loader.injected` — fixes `isReady`/`isFullReady` getting stuck and "Module not found" errors on cold loads of WhatsApp Web ≥ 2.3000 ([#3499](https://github.com/wppconnect-team/wa-js/pull/3499), closes [#3419](https://github.com/wppconnect-team/wa-js/issues/3419))
- **group**: resolve group participants by LID **or** phone number, so participant lookups work on both addressing modes ([#3546](https://github.com/wppconnect-team/wa-js/pull/3546), closes [#3527](https://github.com/wppconnect-team/wa-js/issues/3527))
- **chat**: restore `setChatList()` for LID chats ([#3493](https://github.com/wppconnect-team/wa-js/pull/3493), closes [#3280](https://github.com/wppconnect-team/wa-js/issues/3280))
- **chat**: support `@all` group mentions when sending messages ([#3490](https://github.com/wppconnect-team/wa-js/pull/3490))
- **status**: fix TypeError when sending text status and media status promises never settling ([#3515](https://github.com/wppconnect-team/wa-js/pull/3515), closes [#3466](https://github.com/wppconnect-team/wa-js/issues/3466))
- **chat**: match only the poll-votes table in `getTableVotes()`, avoiding wrong results after WhatsApp DB changes ([#3519](https://github.com/wppconnect-team/wa-js/pull/3519))

### ✨ Features

- **chat**: new `chat.active_filter_changed` event — emitted when the native chat-list filter (All / Unread / Favorites / Groups) changes ([#3492](https://github.com/wppconnect-team/wa-js/pull/3492), closes [#2511](https://github.com/wppconnect-team/wa-js/issues/2511))
- **dev**: `sendTests()` console helper to exercise the message send paths during development ([#3526](https://github.com/wppconnect-team/wa-js/pull/3526))

### ⚠️ Notes

- Partially purged WhatsApp Web versions were dropped from the supported range ([#3502](https://github.com/wppconnect-team/wa-js/pull/3502))
