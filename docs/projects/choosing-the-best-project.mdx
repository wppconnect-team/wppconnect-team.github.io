# Which WPPConnect project should I use?

Choose by where your integration runs. WA-JS runs inside the WhatsApp Web page, the WPPConnect SDK manages the browser from Node.js, and the servers expose HTTP APIs for applications written in other languages.

| Integration | Project | Entry point |
| --- | --- | --- |
| Browser extension or page script | WA-JS | The page's `WPP` object |
| Node.js application that owns the session | WPPConnect | Methods on the `Whatsapp` client |
| Service calling WhatsApp over HTTP | WPPConnect Server or Server Go | The endpoints of the chosen server |

## WA-JS in the browser

WA-JS exposes WhatsApp Web functions for connection management, chats and contacts. When using it directly, your integration manages the browser and the page lifecycle. See the [WA-JS API reference](https://wppconnect.io/wa-js/).

## WPPConnect in Node.js

The SDK manages the browser and exposes client methods and events to your process. Start with [SDK installation](../tutorial/basics/installation.md) and the [messaging and media examples](../tutorial/basics/basic-functions.md).

## HTTP servers

WPPConnect Server exposes SDK operations over REST. See the [Node.js server endpoints](https://wppconnect.io/swagger/wppconnect-server/). [WPPConnect Server Go](https://github.com/wppconnect-team/wppconnect-server-go) is a separate Go implementation. Check the endpoints and authentication in the documentation for the server you plan to run.
